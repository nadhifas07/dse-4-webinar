# dse-4-webinar
Unsupervised Learning (Clustering)
Menjelaskan perbedaan Supervised Learning dan Unsupervised Learning.
Mengidentifikasi algoritma-algoritma dalam Unsupervised Learning.
Menjelaskan konsep dan tujuan Clustering.
Menjelaskan aplikasi clustering untuk Recommendation System, Targeted Marketing, dan Customer Segmentation.
Membedakan Regression, Classification, dan Clustering.
Melakukan analisis menggunakan K-Means Clustering dan Hierarchical Clustering.
Menjelaskan serta menerapkan Principal Component Analysis (PCA).
Menginterpretasikan hasil segmentasi pasar dan pengelompokan wilayah ekonomi.
